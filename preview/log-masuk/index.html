(b) Dalam halaman Akses & dalam dashboard

🏠 Dashboard Pemilik 🚪 Log Keluar Log keluar dari semua peranti

Nota keselamatan dipaparkan: “Peranti kongsi? Tekan Log Keluar selepas selesai.”

Sudah ada dalam sistem: setiap dashboard (pemilik, penyewa, ejen, kontraktor, pembiayaan…) sudah ada butang “Log keluar” sendiri — fungsi signOut() Supabase yang sama. Tambahan ini meletakkannya di tab nav dan halaman akses, supaya pengguna yang berkongsi peranti tidak perlu masuk ke dalam dashboard untuk keluar.

Halaman SEBENAR (boleh klik sekarang, belum dipasang di nav): https://mrtanah.com/portal/masuk.html — paparan belum-log-masuk sudah siap; paparan sudah-log-masuk (kad hijau di atas) hanya muncul apabila akaun benar-benar log masuk.

Cadangan Ali — gabungan A + B (satu tab, satu halaman, semua peranan) + Log Keluar

Kekal mudah untuk pengguna biasa, tetapi lengkap untuk semua jenis akaun.

CADANGAN

1. Nav atas kedua-dua laman dapat tab “Log Masuk” (butang menonjol).
2. Tab itu membuka /portal/masuk.html — halaman kad peranan seperti Pilihan B.
3. Pilih peranan → halaman log masuk (akaun sedia ada) → dashboard auto ikut peranan akaun.
4. Bila sudah log masuk, tab bertukar menjadi “Dashboard saya” (pintasan terus).

Nota teknikal (untuk rekod)

  • Log masuk sedia ada: /portal/login.html (akaun peranan berbilang, satu akaun boleh ada banyak peranan).
  • Senarai peranan → dashboard sudah ada satu sumber kebenaran: portal/assets/auth-nav.js (11 peranan: admin, pemilik, penyewa, kontraktor, ejen, pembeli, penjual, peguamcara, pembiayaan, ladang, tiket aduan).
  • Halaman akses baharu yang dicadangkan: /portal/masuk.html (kad peranan + “Log Masuk”).
  • Tab disyorkan pada: mrtanah.com (semua halaman awam) dan zahirmjproperty.com (pautan ke log masuk yang sama) — untuk kelulusan Zahir.
  • Tiada URL baharu perlu diingat pengguna: mereka hanya perlu tahu satu laman → tab Log Masuk.
